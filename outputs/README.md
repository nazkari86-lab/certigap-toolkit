# CertiGap RKNP 2026 Defense Package

This directory contains the Russian-language defense package prepared for the
Republican Scientific Project Competition (RKNP):

- `CertiGap_RKNP_2026_RU.pptx` - editable 18-slide presentation with speaker notes;
- `CertiGap_RKNP_2026_RU.pdf` - portable presentation export;
- `CertiGap_RKNP_2026_SPEECH_RU.md` - 8-10 minute defense script;
- `CertiGap_RKNP_2026_QA_RU.md` - likely jury questions and evidence-bounded answers.

The numerical claims in the deck are drawn from committed artifacts under
`results/` and follow the boundaries in `docs/CLAIMS.md`. Before competition
submission, add the participant, school, city, and scientific supervisor to
the title slide.
